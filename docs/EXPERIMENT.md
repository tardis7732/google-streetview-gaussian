# 이 도구를 만든 실제 실험

다음은 공개 패키지로 정리하기 **이전**에 진행한 단일 지역 H200 실험 기록입니다. 새 장소에서의 성능 보장이 아닙니다.

| 항목 | 실험 값 |
| --- | --- |
| 입력 촬영월 | 2025년 9월만 사용 |
| 입력 수집 반경 | 100m |
| 확보한 파노라마 | 59개 |
| 시각적으로 등록된 파노라마 | 52개 |
| 제외 | 주 모델에 안정적으로 연결되지 않은 7개 |
| 기본 Gaussian | Brush 40,000 + gsplat 6,000, 최대 400만 |
| 바닥 관측점 | 549개 |
| 바닥 혼합본 | 6,061,600 Gaussian |
| 추가 구멍 보강 | 440,694 Gaussian |
| 보강 후 결과 | 6,502,294 Gaussian |
| 기존 Gaussian 삭제 | 추가 구멍 보강 단계에서 0개 |
| 픽셀 기반 파노라마 | 기존 고정 큐브 투영으로 원본 사진 재추출·재투영 |
| PNG 동시 저장 | 1920×1080 Gaussian / 원본 두 파일 실제 저장 확인 |

10cm 바닥 점유 격자에서 검출한 30㎡ 이하 내부 구멍의 빈 면적은 약 165.67㎡에서 0.30㎡로 줄었습니다. 이는 **선별된 바닥 구멍의 격자 진단**이며 전체 장면의 빈 영역 제거율이나 기하 정확도가 아닙니다. 차량 잔상·전선 깨짐·원본 사진의 변형은 남았습니다.

처음 방식의 SHARP 계열 바닥을 기존 혼합본에서 가져와 공통 카메라로 정렬하고, 확장 구간에는 실제 SfM 도로 관측과 사진 색을 사용했습니다. 확장한 모든 지점에 SHARP를 새로 실행한 결과는 아닙니다. 공개 도구의 `ground --legacy`가 이 선택적 정렬을 담당합니다.

## 공개 패키지에서 확인한 범위

패키지 설치, CLI, 원본 픽셀 중앙 크롭, 큐브 축·경계 표본, 촬영월·반경 제한, 수치적 바닥 적합, 합성 입력의 ground → hybrid → repair → export, 로컬 두 PNG 저장을 CPU 테스트로 검증합니다.

이번 정리 이후 GPU 전체 파이프라인을 새 서버에서 다시 실행하지 않았습니다. 원격 서버 접속 정보와 결과 원본 데이터는 저장소에 넣지 않았습니다. DreamDrive 생성 실험과 이미지 생성 편집물도 이 도구의 재구성 입력이나 예제로 포함하지 않았습니다.
